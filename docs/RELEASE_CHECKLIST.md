# Release checklist

- [ ] Replace all missing profile information and approve all six pages.
- [ ] Confirm exact album/song titles, release order and every album destination.
- [ ] Confirm program and keepsake URLs, final PDF files and signed-out Google Drive download permissions.
- [ ] Run build, structural check and release readiness check successfully.
- [ ] Review desktop/phone layouts, image crops, contrast, readable long statements and both album-link positions.
- [ ] Remove draft notices and noindex only after content is approved and public release is requested.
- [ ] Confirm repository contains no guest lists, rehearsal transcript, private meeting links or production masters.
- [ ] Obtain Charlene’s direction to make the repository public and enable GitHub Pages on the Free account.
- [ ] Confirm the actual Pages URL returned by GitHub; test all relative paths under the project URL.
- [ ] Generate/test the final event QR after the live destination is known. Keep the separate supplied keepsake short link stable.

Nothing in the build or check scripts changes visibility, permissions, hosting, sharing or external services.
